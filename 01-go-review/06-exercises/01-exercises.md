# Вправи по Go (Go Exercises)

Практичні задачі для закріплення навичок. Намагайся робити їх самостійно.

## 1. Базові задачі
- **Реверс рядка** з підтримкою UTF-8 (юнікоду) через `rune`.
- **Полі phonescreen / паліндром** без сторонніх бібліотек.
- **Частоти слів** у тексті з використанням `map[string]int`.

## 2. Структури даних з нуля
- Однозв'язний список (Linked List) з методами `Push`, `Pop`, `Reverse`.
- Стек та черга (Stack & Queue) на базі зрізу.
- Бінарне дерево пошуку (BST) з методами `Insert`, `Search`, `InOrder`.

## 3. Конварентність
- **Worker Pool:** N горутин обробляють спільний канал задач.
- **Fan-in / Fan-out:** Об'єднання результатів з декількох каналів в один.
- **Файтинг race conditions:** Запуск `go run -race main.go` для перевірки гонок.

## 4. Функціонал з реальних проєктів
- Обмеження швидкості (Token Bucket) — див. розділ System Design.
- In-memory кеш з LRU (Least Recently Used) та `sync.RWMutex`.

> Порада: кожну задачу намагайся покрити табличними тестами (`_test.go`).
